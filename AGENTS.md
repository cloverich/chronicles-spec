# Chronicles spec

The contract between Chronicles apps: documents plus golden vectors. Planning lives in Engram (journal **chronicles**); start at **The End is Near** (`03h3idst9x21pgj4wpma4bl80`).

## Working here

- Change a document and its vectors in the same commit. A behavior change regenerates the affected vectors; the diff is the review.
- Encryption vectors: `node scripts/encryption-vectors.mjs` (Node's crypto only) rewrites `vectors/encryption/`. Run from the repository root.
- Export, archive, derive, and contract vectors were generated by the Electron implementation (`UPDATE_VECTORS=1 yarn test:node` in chronicles-electron, which writes its vendored `spec/`); copy any regenerated files back here. Other vectors are written by hand.
- Then bump each app: `Scripts/sync-spec` in chronicles (native), `scripts/sync-spec.sh` in chronicles-electron. Both default to `../chronicles-spec` at `HEAD`; pass a sha to pin.
- Commit messages read as a changelog: a clear conventional subject line.
